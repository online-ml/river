# WrapperEnsemble

A wrapper ensemble is an ensemble composed of multiple copies of the same model.

## Parameters

- **model**

  *Type* → `T`

  The model to copy.
- **n\_models**

  *Type* → `int`

  The number of copies to make.
- **seed**

  *Type* → `int | None`

  Random number generator seed for reproducibility.
