# scale\_values\_in\_dict

Scale the values in a dictionary.

For each element in the dictionary, applies `value * multiplier`.

## Parameters

- **dictionary**

  *Type* → `T`

  Dictionary to scale.
- **multiplier**

  *Type* → `float`

  Scaling value.
- **inplace**

  *Type* → `bool`

  *Default* → `True`

  If True, perform operation in-place
