# Yeast

Yeast multi-label gene-function dataset.

Micro-array expression and phylogenetic profiles for 2417 yeast genes, each annotated with a subset of 14 functional categories. This is the canonical multi-label version from the MULAN library; it matches OpenML dataset id 40597 (`fetch_openml('yeast', version=4)`).
