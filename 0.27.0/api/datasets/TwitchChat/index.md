# TwitchChat

Twitch livestream chat messages.

The data contains 14,720,748 messages from 1,951 livestream sessions by 666 streamers. Each message has an anonymized user identifier, a relative timestamp, and session metadata. The target is the identifier of the game streamed during the session.

## Attributes

- **desc**

  Return the description from the docstring.
- **is\_downloaded**

  Indicate whether or the data has been correctly downloaded.
