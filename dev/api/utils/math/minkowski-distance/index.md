# minkowski\_distance

Minkowski distance.

## Parameters

- **a**

  *Type* → `Mapping[Any, float]`
- **b**

  *Type* → `Mapping[Any, float]`
- **p**

  *Type* → `int`

  Parameter for the Minkowski distance. When `p=1`, this is equivalent to using the Manhattan distance. When `p=2`, this is equivalent to using the Euclidean distance.
