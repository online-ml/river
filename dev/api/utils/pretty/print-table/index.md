# print\_table

Pretty-prints a table.

## Parameters

- **headers**

  *Type* → `Sequence[str]`

  The column names.
- **columns**

  *Type* → `Sequence[Sequence[str]]`

  The column values.
- **order**

  *Type* → `Iterable[int] | None`

  *Default* → `None`

  Order in which to print the column the values. Defaults to the order in which the values are given.
