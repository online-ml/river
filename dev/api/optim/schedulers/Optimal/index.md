# Optimal

Optimal learning schedule as proposed by Léon Bottou.

## Parameters

- **loss**

  *Type* → `optim.losses.Loss`
- **alpha**

  *Type* → `float`

  *Default* → `0.0001`

## Methods

> [!NOTE]
>
> **get**
>
> Returns the learning rate at a given iteration.
>
> **Parameters**
>
> - **t** — `int`
